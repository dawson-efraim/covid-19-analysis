# COVID-19 Data Analysis Project

This project analyzes COVID-19 data using Python with an object-oriented programming approach.

## Project Structure

- `data/` - Contains COVID-19 datasets
- `src/` - Source code organized in OOP structure
  - `data_loader.py` - Handles loading and preprocessing data
  - `analyzer.py` - Performs data analysis
  - `visualizer.py` - Creates visualizations
  - `main.py` - Entry point of the application
- `tests/` - Unit tests
- `requirements.txt` - Python dependencies
- `README.md` - Project documentation

## Features

- Load COVID-19 data from various sources
- Clean and preprocess data
- Perform statistical analysis
- Generate visualizations
- Export results

## Getting Started

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the analysis: `python src/main.py`

## Data Sources

- Johns Hopkins University COVID-19 data
- World Health Organization (WHO) data
- Our World in Data
